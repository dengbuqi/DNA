# Dynamic Neural Architecture (DNA)

> **动态神经网络 | 纯局部学习 | 无反向传播 | 去中心化 AI**

DNA 是一个基于生物神经科学原理构建的神经网络框架。它的核心设计理念——**每个细胞完全自治**，只依赖局部信息学习，不依赖全局反向传播。

---

## 实验结果总结

经过 6 个主要版本、20+ 次迭代的系统性实验后，得到以下结论：

| 版本 | 核心机制 | 最高准确率 | 失败原因 |
|------|---------|-----------|---------|
| v1 | BP + 活力追踪 | 34% | 活力阈值难调，细胞无法稳定分化 |
| v2 | STDP 脉冲 SNN | 10%（随机） | 初始权重太小，脉冲发不出 |
| v3 | 能量预算 + BP | 10% | 能量系统不触发结构变化 |
| **v4** | **局部 Hebbian 规则** | **70.74%** ✅ | **单像素信息天花板** |
| v5 | 感受野 + WTA 竞争 | 53-71% | 竞争机制破坏学习信号 |
| v6 | 纯 Dopamine 奖励 | 10%（随机） | 冷启动失败，永远负奖励 |

### 核心结论

**纯局部 Hebbian 学习（无反向传播）在 MNIST 上能达到约 70% 的测试准确率。** 这是"单像素逻辑回归"的理论上限——因为每个细胞只看到 1 个像素，无法学习空间特征（边缘、形状、纹理）。

要突破 70% 需要：
- 更大的感受野（让细胞看到多个相邻像素）
- 更强的学习信号（即使不是 BP，也需要某种监督信号）
- 更多的训练时间（生物大脑需要数年，不是 15 个 epoch）

## 架构 (v4 最终版)

```
输入 (784 个像素)
  └── 每个像素对应 out_features × cells_per_class 个细胞
      └── 每个细胞绑定一个输出类 (0-9)
          └── 输出 = sigmoid(w × pixel_value)
              └── 每个类的总输出 = 该类所有细胞输出的均值

学习规则 (纯局部，无 BP):
  Δw = lr × pixel_value × (target - output)
  
  其中 target = 1 如果该细胞对应的类等于当前样本标签
       target = 0 否则

结构可塑性:
  能量 = f(输出与目标的接近程度)
  能量 > 阈值 → 细胞分裂 (创造子细胞)
  能量 ≤ 0 → 细胞死亡

  注意: 能量系统的触发频率较低 (约 10+ epoch 才触发一次分裂/死亡)
```

### 为什么不用 BP？

反向传播要求：
1. 每个细胞知道下游细胞的梯度
2. 所有计算在同一个计算图上进行
3. 所有细胞同步更新

而生物大脑不满足以上任何一条。DNA 的局部学习规则符合生物约束：
- 细胞只需要知道自己的输入和输出
- 不需要知道其他细胞的存在
- 可以异步、分布地运行

## 项目历程

这个项目起源于对"可动态增删细胞的神经网络"的好奇。经历数十次实验失败后，最重要的教训是：

1. **生物合理性 ≠ 随机尝试**。生物学经过了亿万年的进化才找到 STDP、多巴胺等机制，简单模仿其表面形式而不理解其功能，必然失败。
2. **纯局部学习有严格的信息上限。** MNIST 上 70% 就是这个上限的实证。
3. **结构可塑性是结果，不是原因。** 细胞分裂/死亡是学习的结果（能量高的细胞分裂、能量低的死亡），而不是学习本身。没有有效的学习规则，结构可塑性毫无意义。
