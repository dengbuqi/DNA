# Dynamic Neural Architecture (DNA)

> **动态神经网络 | 纯局部学习 | 无反向传播 | 去中心化 AI**

DNA 是一个基于生物神经科学原理构建的神经网络框架。它的核心设计理念——**每个细胞完全自治**，只依赖局部信息学习，不依赖全局反向传播。

---

## 实验结果总结

经过 12 个主要版本、30+ 次迭代的系统性实验后，核心结论：

| 版本 | 架构 | 最高准确率 | 关键发现 |
|------|------|-----------|---------|
| v1–v3 | BP + 能量/Vitality | ~34% | 超参数难调，结构可塑性无意义 |
| **v4** | **单像素局部 Hebbian** | **70.74%** | **单像素逻辑回归天花板** |
| v5–v11 | 各种失败尝试 | ~69% | Dopamine/STDP/Extinction 问题 |
| **v12** | **2×2 Patch 分区 + Hebbian** | **69.53%** | Patch 分区稀释信息，不提升 |
| **v13** | **全图连接 Hebbian + Extinction** | **91.70%** | 🏆 **突破 70% 天花板！** |

### 核心结论

**v4: 单像素天花板（70.74%）**
纯局部 Hebbian 学习在 MNIST 上达到约 70%。这是"单像素逻辑回归"的理论上限——每个细胞只看到 1 个像素，无法学习空间特征。

**v12: Patch 分区不能解决问题（69.53%）**
将图像切成 2×2 的 196 个独立 patch，每个 patch 有 3 个细胞独立投票，但信息被分散在 196 个位置，并没有带来提升。

**v13 🏆: 全图连接 + 细胞动态结构（91.70%）**
关键转折：
- **每个细胞看到完整图像**（784 维权重），而不是 patch
- 每个输出类分配多个细胞（3~32 个），形成逻辑回归集成
- **Periodic Extinction**: 每 10 epoch 淘汰因果重要性最低的 1/3 细胞，保持能量
- 从 30 个细胞稳定运行，extinction 后细胞数 20，准确率稳步上升

这证明了：**纯局部 Hebbian 学习 + 动态结构塑性可以在 MNIST 上达到 90%+ 的准确率**，但前提是每个细胞必须看到完整的输入空间，而不是局部 patch。

## 架构 (v13)

```
输入 (784 个像素)
  └── 每个输出类分配 N 个细胞 (初始 3, 最大 32)
      └── 每个细胞有 784 维权重 (连接所有像素)
          └── 输出 = sigmoid(w · x)
              └── 每个类的总输出 = 该类所有细胞输出的均值

学习规则 (纯局部，无 BP):
  Δw = lr × pixel_value × (target - output)
  
  其中 target = 1 如果该细胞对应的类等于当前样本标签
       target = 0 否则

结构可塑性:
  能量 = f(输出与目标的接近程度) - base_cost
  能量 > 150 → 细胞分裂 (子细胞继承 50% 能量 + 权重扰动)
  能量 ≤ 0 → 细胞死亡 (grace period 保护新生细胞)
  每 10 epoch + 递增间隔: 基于因果重要性灭绝 (保留中位数以上细胞)
```

## 快速开始

```bash
cd /mnt/e/DNA
python trainer.py
```

### 依赖
- Python 3.8+
- PyTorch 2.0+ (GPU 推荐)
- torchvision

### 配置
编辑 `trainer.py` 中的 `args` 字典调整参数：
- `patch_size`: 1 (全图) 或 >1 (局部 patch)
- `cells_per_class`: 每类初始细胞数
- `max_cells_per_class`: 每类最大细胞数
- `extinction`: 是否启用周期性灭绝
- `energy_cost`: 能量消耗速率 (越小细胞活得越久)

## 项目历程

这个项目起源于对"可动态增删细胞的神经网络"的好奇。经历数十次实验失败后，最重要的教训是：

1. **生物合理性 ≠ 随机尝试**。生物学经过了亿万年的进化才找到 STDP、多巴胺等机制，简单模仿其表面形式而不理解其功能，必然失败。

2. **Patch 分区是陷阱**。将输入空间切割成独立 patch 并分配独立细胞组，看似"增大感受野"，实际上稀释了每个类的表决权，不如让每个细胞看到全局。

3. **纯局部学习可以达到 90%+**。v13 证明，只要细胞看到完整的输入空间，简单的 Hebbian 规则 + 结构可塑性可以逼近逻辑回归集成性能。

4. **结构可塑性是调节器，不是驱动者**。没有有效的学习规则，结构可塑性毫无意义。但有了好的学习规则后，extinction 可以淘汰冗余细胞、释放能量、防止过拟合。
